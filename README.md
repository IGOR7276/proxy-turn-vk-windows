# WDTT

> Нативный Windows-клиент туннеля через VK TURN на базе WireGuard.

Форк [proxy-turn-vk-android](https://github.com/amurcanov/proxy-turn-vk-android) с полностью переписанным десктопным UI на [Wails](https://wails.io).

---

## Возможности

### 🔌 Туннель
- Выбор сервера, настройка VK-хешей, вставка `wdtt://` ссылок
- Импорт профилей из `.qwdtt`
- Быстрое переключение между сохранёнными профилями

### ☁️ Деплой VPS
- Установка `wdtt-server` на сервер по SSH (логин/пароль)
- Автонастройка systemd-сервиса, iptables NAT, MSS clamping
- Telegram-бот: уведомления о подключениях, управление доступом

### 🔐 Авторизация VK
Два режима получения TURN-кредов:

| Режим | Описание |
|-------|----------|
| **Анонимный** (по умолчанию) | Автоматическое получение TURN через API VK. Работает без ручного входа |
| **Через аккаунт** | Вход в VK через WebView2 — **резервный способ** на случай, если анонимный режим заблокирован. Максимум 4 потока |

При включённом режиме «Через аккаунт» вход выполняется через вк в новом окне, при нажатии «Подключить». Далее открывается окно с подключением в звонок, где нужно нажать продолжить в браузере, далее получаются TURN-креды и поднимается тунель (после подключения окно с звонком можно закрыть). Благодаря тому что WebView2 хранит cookies, повторный вход не требуется.

### 📋 Логи
- Live-tail всех событий туннеля, деплоя и авторизации VK

### ⚙️ Настройки
- DNS-прокси, AutoWG, MTU, Трей, Режим авторизации, глобальные хеши.
- Тема оформления (светлая / тёмная).

### 📊 Инфо
- Версия приложения, статистика сессии, канал обновлений

## Требования

- **Windows 10/11 x64**
- **Запуск от имени администратора** (требуется доступ к WireGuard-драйверу)
- VPS с Linux (Debian 11+, Ubuntu 20.04+, CentOS/RHEL/Fedora/AlmaLinux/Rocky) и открытыми портами:
  - `22` TCP (SSH)
  - `56000` UDP (DTLS)
  - `56001` UDP (WireGuard)
- VK-аккаунт с хешем звонка

## 🚀 Запуск

1. Скачайте последний релиз из [releases](https://github.com/IGOR7276/proxy-turn-vk-windows/releases)
2. Запустите `wdtt.exe` **от имени администратора**

## 🔧 Сборка из исходников

```powershell
# Установка Wails
go install github.com/wailsapp/wails/v2/cmd/wails@latest

# Клонирование
git clone https://github.com/IGOR7276/proxy-turn-vk-windows.git
cd proxy-turn-vk-windows

# Полная сборка
wails build
```

Результат: `build/bin/wdtt.exe`


## 🔑 Получить VK-хеш

VK → Сообщество → Звонок → «Пригласить» → скопировать ссылку:

```
https://vk.com/call/join?hash=XXXXXXXXX

```

Вставить в приложение.
